Am I Compromised? checks a user's iPhone and Mac for KNOWN traces of mercenary spyware and stalkerware, using public indicator lists (the mvt-indicators index maintained by Amnesty International's Mobile Verification Toolkit project). It is not an antivirus, makes no zero-day claims, and says on first launch and under every result that a clean result can't prove a device is clean. No login, no ads, no analytics.

HOW TO REVIEW (IPHONE, NO SETUP NEEDED)
1. Accept the "Before you start" screen.
2. Tap Scan Now. It downloads the latest public lists from GitHub, then shows the software-update check and device checks.
3. Spyware log scan: open "Spyware log scan" and tap "Try a sample scan" at the bottom. It scans bundled, clearly labelled made-up data with two planted traces, showing findings and the "what to do" section. It never affects the user's real status.
4. A real scan needs a sysdiagnose, which iOS only creates when the user presses both volume buttons and the side button together. The user then shares it from Settings › Privacy & Security › Analytics & Improvements › Analytics Data using the "Scan for Spyware" share action, which copies the file into the app; the app scans it on the device.

WHY NO DATA LEAVES THE DEVICE
The app only downloads public lists (raw.githubusercontent.com). Logs, backups, backup passwords and results are processed and kept on the device. The open-source code is at https://github.com/shiftingeden/AmICompromised.

MAC
The Mac version (same app, Universal Purchase) scans an iPhone backup folder the user chooses in Finder (sandboxed, user-selected read-only access) and checks the macOS version against exploited bugs. To review without a backup, open Log Files and choose any folder of text logs.

CODE SHARED WITH THE FREE MAC DOWNLOAD (disclosed under 2.3.1)
The Mac code is also built, outside the App Store, as a free Developer ID download on GitHub. Two compile-time switches separate the builds, and neither can change after review:
- fullAccess: false in this build. The engine's broader Mac system scan (settings, startup items, profiles) is compiled in but unreachable here; the sandbox would block it anyway.
- storeAvailable: true in this build. Tips use the App Store. In the GitHub download it is false, the tip jar is hidden and the themes are simply unlocked, because that download can't use App Store payments.
There is no remote switch and no hidden menu.

IN-APP PURCHASES
Four optional consumable tips. Every feature is free; tipping unlocks Orange and Gold alternate app icons and six accent colour themes (Navy icon and Ocean theme are always free). Restore Earlier Tip is on the Support screen.

BACKGROUND PROTECTION (opt-in, Protection screen on the home screen)
Off by default. When the user turns it on, the app uses Background App Refresh (BGAppRefreshTask) to: download the latest public spyware lists, re-check the traces saved from the user's last sysdiagnose scan against them (domains, process names, paths seen in that scan, stored only on the device), warn about newly exploited iOS bugs, and remind the user to restart every few days. iOS decides when it runs; the interval setting is a request. To try it: open Protection, turn on Background checks, tap "Run a check now".

NOTIFICATIONS
Local only. Uses: "your sysdiagnose should be ready"; restart reminders; update warnings; and, if a background re-check matches a published list, a time-sensitive alert with two buttons. "Cut connections" opens the app, which runs a Shortcut the user created themselves (named "Am I Compromised Emergency", with the standard Set Airplane Mode action) through the shortcuts:// URL; the app never changes settings itself. "Not now" dismisses. Setup steps are on the Protection screen.

WIDGET
Home/Lock Screen widgets (status, last check, next-check timer, days since restart) with Scan Now and Cut buttons; matching controls (iOS 18+) and Siri actions. Each opens the app; Cut runs the user's Shortcut.
