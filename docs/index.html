Am I Compromised?

Check your iPhone and Mac for known traces of spyware. Free and open source.

No guarantee. The app looks for known traces of mercenary spyware and stalkerware, using public lists from Amnesty International, Citizen Lab, iVerify and others. New spyware has no public traces until researchers catch it, so a clean result can't prove a device is clean, and a match is a lead, not proof.

What it checks

  • Software updates: whether your iOS or macOS version has bugs that are being used in real attacks (CISA's Known Exploited Vulnerabilities list).
  • iPhone logs: a sysdiagnose you create and share to the app, scanned for spyware domains, process names and file paths.
  • iPhone backups (on a Mac): installed apps, messages, browser history, data usage and configuration profiles.
  • This Mac: security settings, running programs, startup items, profiles and more (full version).
